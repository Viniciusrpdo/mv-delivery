# MV Delivery

O **MV Delivery** é um projeto autoral que estou desenvolvendo durante o curso de Desenvolvimento de Sistemas no SENAC.

A ideia surgiu da minha própria rotina de trabalho com entregas de moto. Como já tenho contato com esse tipo de serviço no dia a dia, escolhi desenvolver um sistema relacionado a delivery dentro dos requisitos propostos no Projeto Integrador do curso.

## Etapa atual

No momento, o projeto está na etapa de banco de dados.

Nesta versão foram trabalhados:

* cadastro de clientes;
* cadastro de entregadores;
* pedidos;
* histórico de status;
* feedbacks;
* relacionamentos entre tabelas;
* operações de inserção, consulta, atualização e exclusão de dados.

## Tecnologias utilizadas

* SQL
* MySQL
